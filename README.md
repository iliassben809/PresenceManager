# PrésenceManager — TP01

## Description
PrésenceManager est une application Android développée dans le cadre du module M203 — Interfaces utilisateurs Android.

Ce projet consiste à créer une interface d'accueil moderne et simple permettant de découvrir l'application de gestion de présence.

## Technologies utilisées
- Kotlin
- XML
- Android Studio
